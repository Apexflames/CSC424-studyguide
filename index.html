Topic 1

Introduction to Application Packages

Meaning of Application Packages

Source Material Application packages are computer programs designed to help users perform specific tasks or solve particular problems. Unlike system software, which manages computer hardware and system resources, application packages assist users in activities such as document preparation, data analysis, communication, database management, graphics design, and presentation creation.
Plain English System software is the engine of the car; application packages are what you actually drive it for — writing a letter, running a budget, editing a photo.

Examples: Microsoft Word, Excel, PowerPoint, Access, SPSS, Adobe Photoshop, CorelDRAW, Google Workspace applications.

Historical Development

Source Material Early computers were used for scientific/military applications and required custom programming. Personal computers in the 1970s–80s brought packages like WordStar, Lotus 1-2-3 and dBase, letting ordinary users do office tasks without programming. GUIs then replaced command-line interfaces, and Microsoft Office became one of the most widely used suites. Today, cloud computing and mobile technology have made application packages web-based and mobile-accessible, supporting collaboration and remote work.

Characteristics of Application Packages

Source Material User-Friendliness, Task-Specific Functionality (e.g. Excel focuses on numerical computation), Reliability, Integration Capability, Customization, Security Features (password protection, encryption, access control), and Automation (macros, scripts, built-in functions).

Importance of Application Packages

  • Improve productivity — reduce time to complete tasks
  • Enhance accuracy — minimize human error
  • Facilitate communication — email, presentation, collaboration platforms
  • Support decision-making — analysis, forecasting, reporting
  • Assist teaching, learning, research and administration in education

Likely Exam Questions Likely

Define Application Packages and distinguish them from System Software.
Answer: Application packages are programs designed to help users perform specific tasks (e.g. document preparation, data analysis), while system software manages hardware and system resources and provides the platform on which applications run. System software controls hardware and runs in the background; application software performs user tasks and runs when needed.

Word Processing Applications

Introduction & Features

Source Material Word processing is the use of computer software to create, edit, format, store, retrieve and print text-based documents. Microsoft Word features: Text Editing, Formatting Tools, Spell Checking, AutoCorrect, Templates, Find and Replace, and Printing Options.

Document Formatting

LevelIncludes
Character FormattingFont type, size, color, bold, italics, underline
Paragraph FormattingAlignment, indentation, line spacing, paragraph spacing, bullets/numbering
Page FormattingMargins, orientation, page size, columns, headers/footers

Styles are predefined formatting settings ensuring consistency; Themes coordinate fonts, colours and effects across a document.

Mail Merge

Source Material Mail Merge creates multiple personalized documents from a single template, combining a Main Document, a Data Source, and Merge Fields. Example: a university generating admission letters for thousands of students from one template and a student database. Benefits: time savings, accuracy, consistency.

References and Citations

Word provides Citations, Bibliographies, Footnotes, Endnotes, Table of Contents. Supported styles: APA, MLA, Chicago, Harvard. Mendeley is commonly used for automatic citation and referencing.

Creation of Professional Reports

Live Animation
Standard report structure

Quick Revision Word processing = create/edit/format/store/print text documents. Formatting has three levels: character, paragraph, page. Mail Merge = Main Document + Data Source + Merge Fields. Reports follow 8 fixed sections: Title Page → Abstract → TOC → Introduction → Main Body → Conclusion → References → Appendices.

Likely Exam Questions Likely

Explain Mail Merge and its three components, with an example.
Answer: Mail Merge lets a user create multiple personalized documents from one template. It combines a Main Document (the template), a Data Source (e.g. a student database), and Merge Fields (placeholders that pull in each record's data) — e.g. a university generating thousands of individualised admission letters from one template.
Study Guide Reference: Topic 2 → Mail Merge
Differentiate between Character, Paragraph, and Page formatting in Microsoft Word.
Answer: Character formatting modifies text itself (font, size, colour, bold/italic/underline); Paragraph formatting controls a paragraph's layout (alignment, indentation, spacing, bullets/numbering); Page formatting controls the whole page (margins, orientation, size, columns, headers/footers).
Study Guide Reference: Topic 2 → Document Formatting
Outline the standard structure of a professional report.
Answer: Title Page, Abstract, Table of Contents, Introduction, Main Body, Conclusion, References, Appendices.
Study Guide Reference: Topic 2 → Creation of Professional Reports

Formulas vs Functions

Source Material A formula is an expression used to perform calculations, always beginning with "=" (e.g. =A1+B1, =A2*B2). A function is a predefined formula that performs a specific calculation.
Live Animation
Common Excel functions

Charts, Sorting/Filtering, Pivot Tables, What-If Analysis

Chart types: Column, Bar, Pie, Line, Area, Scatter. Sorting: ascending, descending, alphabetically. Filtering: displays only records meeting specified conditions.

Source Material A Pivot Table is an advanced feature for summarizing and analysing large amounts of data — grouping information, calculating totals, comparing categories, and generating reports. What-If Analysis predicts outcomes by changing input values, using Goal Seek, Scenario Manager, and Data Tables.

Financial and Statistical Calculations

Financial: loan repayment analysis, interest computation, investment evaluation, budget planning. Statistical: mean, median, mode, standard deviation, variance, correlation analysis.

Quick Revision Workbook → Worksheet → Cell hierarchy. Formulas start with "="; functions are predefined formulas (SUM, AVERAGE, MAX, MIN, COUNT, IF). Pivot Tables summarize large datasets; What-If Analysis (Goal Seek, Scenario Manager, Data Tables) predicts outcomes.

Likely Exam Questions Likely

Differentiate between a formula and a function in Excel, giving an example of each.
Answer: A formula is a user-written expression for a calculation, always starting with "=" (e.g. =A1+B1). A function is a predefined, built-in formula for a specific calculation (e.g. =SUM(A1:A10)).
Study Guide Reference: Topic 3 → Formulas vs Functions
What is a Pivot Table used for, and what is What-If Analysis?
Answer: A Pivot Table summarizes and analyses large datasets — grouping data, calculating totals, comparing categories, generating reports. What-If Analysis predicts outcomes by changing input values, using tools such as Goal Seek, Scenario Manager, and Data Tables — used for budgeting, forecasting, and strategic planning.
Study Guide Reference: Topic 3 → Charts, Sorting/Filtering, Pivot Tables, What-If Analysis

Presentation Packages

Introduction

Source Material Presentation software creates, organises and displays information visually to an audience, combining text, images, charts, animations, audio and video into slides. Examples: Microsoft PowerPoint, Google Slides, Apple Keynote, LibreOffice Impress, Prezi, Canva Presentation.

PowerPoint environment components: Title Bar, Ribbon (Home, Insert, Design, Transitions, Animations, Slide Show, Review, View), Slides Pane, Slide Workspace, Notes Section, Status Bar.

Creating a Presentation

Live Animation
Building an effective presentation

Slide Design Principles

Source Material Simplicity, Consistency, Readability, Contrast, Balance, Relevance, White Space.

Animation vs Transition

AnimationTransition
Effect applied to an object within a slide (entrance, emphasis, exit, motion path)Effect applied between two slides (fade, push, wipe, split, morph)

Excessive animation/transitions may distract the audience — it is advisable to use little or none in most professional presentations.

Delivery Techniques

  • Understand the content thoroughly before presenting
  • Maintain eye contact with the audience
  • Speak clearly, at an appropriate pace
  • Use body language, facial expressions and gestures to support the message
  • Avoid reading directly from slides
  • Handle audience questions professionally and confidently
  • Prepare and rehearse to reduce anxiety and improve quality
Quick Revision Presentation = slides combining text/media, delivered to an audience. Design principles: simplicity, consistency, readability, contrast, balance, relevance, white space. Animation = within a slide; Transition = between slides — use sparingly.

Likely Exam Questions Likely

Differentiate between Animation and Transition effects in presentation software.
Answer: Animation effects are applied to objects within a single slide (entrance, emphasis, exit, motion path effects), while Transition effects control how one slide changes to the next (e.g. fade, push, wipe, split, morph).
Study Guide Reference: Topic 4 → Animation vs Transition
State five slide design principles and explain any two.
Answer: Simplicity, Consistency, Readability, Contrast, Balance, Relevance, White Space. Simplicity means slides should hold only essential information since overcrowding confuses the audience; Contrast means there must be sufficient difference between text and background colour for visibility.
Study Guide Reference: Topic 4 → Slide Design Principles
Explain the steps involved in creating an effective presentation.
Answer: Identify the purpose and target audience; gather and organise relevant information; create and arrange slides logically into an Introduction (topic and objectives), Main Body (key points and supporting information), and Conclusion (summary and closing remarks).
Study Guide Reference: Topic 4 → Creating a Presentation

Define a DBMS and state its major functions.

Differentiate between a Record and a Field, and explain the role of a Primary Key.

Statistical and Data Analysis Packages

Introduction to SPSS

Source Material SPSS (Statistical Package for the Social Sciences) was originally developed for social science research but is now used across many disciplines. It provides tools for data entry, data management, statistical analysis, report generation, and data visualization, popular for its graphical interface requiring no extensive programming knowledge.

Data View vs Variable View

Data ViewVariable View
Spreadsheet-like entry screen; each row = a case/observation, each column = a variableDefines variable properties: name, data type, width, decimal places, labels, missing values, measurement scale

Coding assigns numerical values to categories, e.g. Gender: Male = 1, Female = 2.

The Data Analysis Process

Live Animation
From raw data to interpreted results

Descriptive vs Inferential Statistics

Descriptive StatisticsInferential Statistics
Summarizes/describes data: Mean, Median, Mode, Range, Standard DeviationUses sample data to draw conclusions about a population: Hypothesis Testing, t-Test, ANOVA, Chi-Square Test, Correlation Analysis
Quick Revision SPSS: Data View (cases × variables, spreadsheet-like) vs Variable View (defines each variable's properties). Process: Data Entry & Coding → Cleaning & Validation → Descriptive Statistics → Inferential Statistics → Interpretation. Descriptive summarizes a sample; Inferential generalizes to a population.

Likely Exam Questions Likely

Differentiate between Data View and Variable View in SPSS.
Answer: Data View resembles a spreadsheet where actual data values are entered — each row is a case/observation, each column a variable. Variable View instead defines each variable's characteristics: name, data type, width, decimal places, labels, missing values, and measurement scale.
Study Guide Reference: Topic 6 → Data View vs Variable View
Differentiate between Descriptive and Inferential Statistics, with two examples of each.
Answer: Descriptive statistics summarize and describe the characteristics of the data itself — e.g. Mean and Standard Deviation. Inferential statistics use sample data to draw conclusions about a larger population — e.g. t-Test and ANOVA.
Study Guide Reference: Topic 6 → Descriptive vs Inferential Statistics
What is "coding" in SPSS data entry? Give an example.
Answer: Coding is the assignment of numerical values to categorical data to simplify processing and statistical analysis — e.g. coding Gender as Male = 1, Female = 2. Accurate coding ensures reliable research results.
Study Guide Reference: Topic 6 → Data View vs Variable View

Cloud Computing

Source Material Cloud computing is the delivery of computing services — storage, software, databases, networking, processing power — over the Internet, instead of on a local computer. It reduces infrastructure cost and increases accessibility. Providers include Google, Microsoft, and Amazon Web Services.

Likely Exam Questions Likely

Define Cloud Computing and list its five characteristics.

Graphics and Multimedia Applications

Introduction & Design Principles

Source Material Graphics applications create, edit, and manipulate visual content used in advertising, education, entertainment, publishing, and digital marketing. Graphic design principles: Balance, Alignment, Contrast, Repetition, Proximity, White Space.

Photoshop vs CorelDRAW

Adobe PhotoshopCorelDRAW
Raster graphics editor — works with pixelsVector graphics application — works with mathematical paths
Loses quality when resized significantlyCan be resized without losing quality
Photo editing, image enhancement, retouching, digital paintingLogo design, banners, signage, business cards, brochures
Key concepts: Layers, Selection Tools, Filters, Brushes, Adjustment ToolsKey features: Vector Drawing Tools, Text Tools, Colour Management, Object Manipulation

Image Editing vs Image Manipulation

Editing: cropping, resizing, colour correction, background removal, retouching, noise reduction — improving quality. Manipulation: more advanced alterations that may significantly transform the original image.

Quick Revision Photoshop = raster (pixels, loses quality when resized); CorelDRAW = vector (paths, scales without loss). Six design principles: Balance, Alignment, Contrast, Repetition, Proximity, White Space. Editing improves an image; Manipulation transforms it.

Likely Exam Questions Likely

Differentiate between raster graphics (Photoshop) and vector graphics (CorelDRAW).
Answer: Photoshop is a raster graphics editor that works with pixels, so images lose quality when resized significantly. CorelDRAW is a vector graphics application that uses mathematical paths, allowing graphics to be resized without losing quality — making it well suited to logos, banners and signage.
Study Guide Reference: Topic 8 → Photoshop vs CorelDRAW
List the six principles of graphic design.
Answer: Balance, Alignment, Contrast, Repetition, Proximity, White Space.
Study Guide Reference: Topic 8 → Introduction & Design Principles
Distinguish between image editing and image manipulation.
Answer: Image editing involves modifying an image to improve quality or achieve a desired effect (cropping, resizing, colour correction, retouching). Image manipulation refers to more advanced alterations that may significantly transform the original image.
Study Guide Reference: Topic 8 → Image Editing vs Image Manipulation

Application Integration

Introduction & Data Import/Export

Source Material Application integration enables different software applications to communicate, exchange data, and work together, preventing duplicated or inconsistent information. Common file formats for import/export: CSV, XLSX, DOCX, PDF, XML, JSON.

Linking vs Embedding (OLE)

LinkingEmbedding
Object stays connected to the original source file; updates automatically when the source changesObject becomes part of the destination document, independent of the original file

Example: an Excel chart inserted into a Word document can be either linked or embedded.

Office Application Integration

PairingUse
Word + ExcelInsert Excel tables/charts into Word reports
Access + ExcelExport Access data to Excel for analysis
Access + WordUse database information for mail merge
Excel + PowerPointInsert charts/results into slides
Access + PowerPointIncorporate database reports into presentations

Automated Reporting Systems

Systems that collect data, process it, and generate reports automatically with minimal human intervention. Benefits: improved accuracy, time savings, reduced workload, consistent reporting — common in banking, healthcare, education, manufacturing, government.

Quick Revision Integration = apps exchanging data (CSV, XLSX, DOCX, PDF, XML, JSON). Linking = stays connected to source, auto-updates; Embedding = becomes independent of source. Office apps integrate in pairs (Word+Excel, Access+Word for mail merge, etc.). Automated reporting = minimal-intervention, rule-based report generation.

Likely Exam Questions Likely

Differentiate between Linking and Embedding an object (OLE).
Answer: A linked object remains connected to its original source file — changes to the source automatically update the linked copy. An embedded object becomes part of the destination document and is independent of the original file, so later changes to the source do not affect it.
Study Guide Reference: Topic 9 → Linking vs Embedding
Give three examples of how Microsoft Office applications integrate with one another.
Answer: Excel tables/charts inserted into Word reports; Access database information used for a Word mail merge; Excel charts and analytical results inserted into PowerPoint slides.
Study Guide Reference: Topic 9 → Office Application Integration
What is an Automated Reporting System, and what are its benefits?
Answer: A system that collects data, processes it, and generates reports automatically according to predefined rules, with minimal human intervention. Benefits: improved accuracy, time savings, reduced workload, and consistent reporting.
Study Guide Reference: Topic 9 → Automated Reporting Systems
